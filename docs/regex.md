## 3. อีเมล — `email` (คนที่ 3)

**Pattern**

```python
pattern = re.compile(
    r"""
    (?<![\w.+-])
    (?P<target>
        [A-Za-z0-9]
        (?:[A-Za-z0-9._%+-]*[A-Za-z0-9])?
    )
    @
    (?P<domain>
        [A-Za-z0-9](?:[A-Za-z0-9-]*[A-Za-z0-9])?
        (?:\.[A-Za-z0-9](?:[A-Za-z0-9-]*[A-Za-z0-9])?)+
    )
    (?![\w.-])
    """,
    re.VERBOSE,
)
```

**อธิบายทีละส่วน**

| ส่วน | ความหมาย |
|---|---|
| `(?<![\w.+-])` | negative lookbehind — กัน username ไม่ให้ถูกตัดกลางคำ/ต่อจาก mention เช่น `@somchai` |
| `(?P<target>...)` | named group ครอบเฉพาะ username — เอนจินจะ mask แค่ช่วงนี้ ส่วน `@domain` ถูกเก็บไว้เดิมโดยอัตโนมัติ |
| `[A-Za-z0-9]` (ตัวแรกใน target) | บังคับให้ username เริ่มด้วยตัวอักษร/ตัวเลข ไม่ใช่จุดหรือขีด |
| `(?:[A-Za-z0-9._%+-]*[A-Za-z0-9])?` | ตัวกลาง username (จุด ขีด บวก % ได้) แต่ต้องจบด้วยตัวอักษร/ตัวเลขเสมอ |
| `(?P<domain>...)` | ตรวจว่าหลัง `@` ต้องเป็นโดเมนจริง (มี label คั่นด้วยจุดอย่างน้อย 1 จุด เช่น `.com`, `.co.th`) |
| `(?![\w.-])` | negative lookahead — กันโดเมนโดนตัดกลางคัน (เช่นไม่ให้ไปกินตัวอักษรที่ตามหลังโดเมนต่อ) |

**ทำไมถึงเลือกแบบนี้** — ใช้ named group `target` ครอบเฉพาะ username เพื่อให้เอนจิน mask
เฉพาะช่วงนั้น ไม่ต้องเขียน mask() ให้คืนทั้ง `user@domain` เอง (เทคนิคเดียวกับที่ dob/address ใช้
ครอบเฉพาะส่วนที่ต้องปิด) ส่วนจำนวน `*` ต้องคำนวณตอน runtime จากความยาว username
(`len(username) - 2` ตัว เพราะเก็บตัวแรก+ตัวสุดท้ายไว้) จึงต้องใช้เมธอด `mask()` แบบ callback
แทนการส่ง string แทนที่ตรง ๆ

**เคสที่จงใจไม่จับ** — `@somchai กล่าวว่า` (mention ไม่มี username นำหน้า @),
`ราคา 100@ชิ้น` (หลัง @ ไม่ใช่โดเมนจริง ไม่มีจุด+ตัวอักษรละติน), `user@` (ไม่มีโดเมนต่อท้ายเลย)

**ข้อจำกัดที่รู้ตัว** — username ยาว 1–2 ตัวจะไม่ถูกปิดเลย เพราะตัวแรก/ตัวสุดท้ายชนกัน
(เอกสารโจทย์ไม่ได้ระบุเคสนี้ไว้ชัดเจน จึงตัดสินใจเองว่าให้คงค่าเดิม); ไม่รองรับ
username ที่เป็น IP-domain หรือ email แบบ quoted-string ตาม RFC เต็มรูปแบบ เพราะเกินขอบเขต
ของ log ธนาคารที่โจทย์กำหนด

## เทคนิคที่โปรเจกต์นี้ใช้ (สรุปสำหรับพรีเซนต์)

| เทคนิค | ใช้ที่ไหน | ทำไม |
|---|---|---|
| `re.VERBOSE` | ทุกกฎ | เขียน pattern หลายบรรทัดพร้อมคอมเมนต์ได้ |
| named group `(?P<name>...)` | email, dob, address | อ้างถึงส่วนย่อยตอน mask และระบุช่วง `target` |
| non-capturing `(?:...)` | address, phone | จัดกลุ่มโดยไม่กินหมายเลข group |
| callback ตอนแทนที่ | ทุกกฎ (เมธอด `mask()`) | ผลลัพธ์ขึ้นกับความยาว/เนื้อหาของ match |
| lookaround | credit_card, phone | กันจับเลขที่ยาวเกินหรือติดกับตัวอักษรอื่น |
| post-validation | dob (วัน/เดือน), credit_card (Luhn) | เงื่อนไขที่เขียนเป็น regex แล้วอ่านไม่รู้เรื่อง |
